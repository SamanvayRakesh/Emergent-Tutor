# NeuraLearn - AI-Powered CBSE Learning Platform

## Overview
Production-level AI-powered CBSE learning platform with **verified NCERT curriculum engine**, gamification, and cinematic royal-palette UI (red/blue/gold).

## Architecture
- **Frontend**: React 18 + TailwindCSS + Framer Motion + Three.js + Recharts + Redux Toolkit
- **Backend**: FastAPI (modular routers) + Motor (MongoDB async)
- **Curriculum**: NCERT-verified manifest engine (real ncert.nic.in PDFs + cross-referenced chapter titles)
- **AI**: OpenAI GPT-4o (user's own key) via streaming SSE, grounded to verified chapter manifest
- **DB**: MongoDB (test_database, `db.curriculum` indexed by class+subject+year)
- **Auth**: JWT + Emergent Google OAuth

### Phase 3 — Verified NCERT Curriculum Engine (Feb 2026)
- **Scraper** at `/app/backend/scripts/ncert_scraper.py`:
  - Reads `ncert_books.json` (25 verified books, classes 6–12, English-medium only, subjects: Math, Science, English, Social Science)
  - Downloads real NCERT PDFs from `ncert.nic.in/textbook/pdf/{book_code}{chapter_id}.pdf`
  - Validates PDFs by magic-byte check (`%PDF`)
  - Cross-references chapter titles via learncbse.in / byjus.com
  - Outputs structured `ncert_ai_metadata.json`
  - Async with semaphore (3 concurrent), tenacity retry with exponential backoff
- **Curriculum engine** (`curriculum_engine.py`):
  - Loads metadata into in-memory cache + MongoDB on startup
  - Provides `get_verified_chapters(class, subject)` for backend
  - Provides `build_ai_chapter_manifest(class, subject)` — injected into AI tutor system prompt for **hallucination guard** (AI must prefix off-syllabus answers with "Note: not in official NCERT chapters")
- **API endpoints**:
  - `GET /api/curriculum/status` — engine coverage info
  - `POST /api/curriculum/refresh` — admin-only scraper re-run
  - `GET /api/syllabus/classes` — now includes `verified: true/false` per class
  - `GET /api/syllabus/{class}/subjects` — verified flag per subject
  - `GET /api/syllabus/{class}/{subject}/chapters` — verified chapter list with `pdf_url`, `book_code`, `book_title`, `chapter_no`
- **UI**: SyllabusPage shows "NCERT ✓" badge on verified subjects/chapters + direct link to source NCERT PDF for each chapter
